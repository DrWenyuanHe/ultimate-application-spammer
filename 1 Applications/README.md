# 1 Applications

One folder for each application that was submitted, named with the date and the job, for example `2026-11-25 Employer - Role` (or `2026-11 Employer - Role` when only the month is known).

Each folder holds exactly what was filed: the documents uploaded, a `submission.json` record, and `What I submitted.md` with any text pasted into the form, every question and the answer given, who submitted it, and the confirmation received. Reread it before an interview.

Documents still being prepared are in `Drafts/`, one folder per job.

Everything here stays on your computer and is excluded from Git.

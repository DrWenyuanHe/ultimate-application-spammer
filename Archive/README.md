# Archive

Anything moved out of the way ends up here instead of being deleted: old drafts, files you edited before the app refreshed them, and database backups made before each update.

Items are named `YYYY-MM-DD HHMM original name`. `archive-log.csv` records where each one came from and why it was moved.

`Clearable/` holds things the clean-up moved aside (temporary files, old logs, old backups), sorted by type. They are safe to delete.

You can delete anything in this folder yourself whenever you like. Your assistant never deletes anything, here or anywhere else. Keep the newest `before vX.Y.Z database.sqlite` backup if you might want to undo an update.
